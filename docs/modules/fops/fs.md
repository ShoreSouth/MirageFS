# FS 级操作

fs 类操作作用于文件系统实例，而不是单个普通对象。

## statfs

`fops_statfs()` 查询文件系统容量、块大小、可用空间、文件数等信息。

必要输入：

- 文件系统上下文或根对象身份。

输出：

- `fops_statfs_t` 或等价统计结构。

statfs 不应注册或创建新对象，只读取当前后端状态。

## syncfs

`fops_syncfs()` 将文件系统级脏数据同步到底层后端。

必要输入：

- 文件系统上下文或根对象身份。

syncfs 应覆盖元数据和数据的同步需求；如果底层只能提供部分同步，应在返回值或文档中明确弱语义。

## 与 FSC 的边界

FSC 管理文件系统实例、root、mount/namespace 等信息。FOPS 的 fs 级操作只通过 FSC 获取上下文，不应反向维护一套文件系统注册表。
