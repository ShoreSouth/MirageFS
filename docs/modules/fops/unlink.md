# Unlink 操作

unlink 负责删除父目录下的非目录目录项。

## 参数语义

必要输入：

- `parent_fuid`：父目录对象。
- `name`：待删除目录项名称。
- `flags`：删除控制标志。

输出通常为空；成功表示目录项已被移除。

## flag 语义

unlink 推荐支持：

- `FS_FLAG_NOFOLLOW`：删除符号链接本身，而不是跟随目标。
- `FS_FLAG_REGULAR`：要求删除目标是普通文件或非目录对象。

目录删除必须走 rmdir，不应由 unlink 隐式删除目录。

## 生命周期

unlink 删除的是目录项引用。对象是否立即销毁取决于链接计数、打开句柄和 ObjMgr 生命周期状态。

FOPS 需要配合 ObjMgr 标记对象状态，避免目录项已消失但运行时对象仍被打开时发生悬空引用。
